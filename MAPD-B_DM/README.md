# Management and Analysis of Physics Dataset - Part B (Data Management)

## Overview
This project implements a RAID-4 software redundancy system and explores various data management techniques using Python.

## Contents

### Main Assignment
**Final_assignment_MAPDB_Filippo_Conforto.ipynb**: Comprehensive notebook covering:
- **Fun Exercise**: XOR operations and bitwise manipulation
- **RAID-4 Implementation**: Software-based redundancy system
  - Splitting data across multiple files (raid4.0 - raid4.4)
  - Parity calculation using XOR operations
  - Data recovery from corrupted files
  - Performance analysis

### Files
- **raid4.0 - raid4.4**: RAID data and parity files
- **Final_assignment.tex**: LaTeX report source
- **secnum.tplx**: Template for notebook conversion
- **Final_assignment_files/**: Supporting files and figures

## Concepts Covered
- Redundancy and fault tolerance (RAID-4)
- Bitwise operations and XOR
- Data striping and parity
- File I/O in Python
- Data recovery algorithms

## Technologies
- **Language**: Python
- **Key Libraries**: NumPy, Matplotlib, json, functools
- **Format**: Jupyter Notebook, LaTeX
