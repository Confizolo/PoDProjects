## Overview
This directory contains homework assignments for the Reinforcement Learning course, covering fundamental RL algorithms and techniques.

## Contents

### Homework Assignments
- **ConfortoFilippo_hw01.ipynb**: First homework assignment
  - Multi-Armed Bandits (MAB) problem

- **HW2_FilippoConforto_2021856.ipynb**: Second homework assignment

## Topics Covered
- **Multi-Armed Bandits**: Exploration vs. exploitation tradeoffs
- **Dynamic Programming**: Value iteration, policy iteration
- **Nonstationary Environments**: Random walk dynamics in reward distributions
- **Algorithm Comparison**: Sample averaging vs. constant step-size methods
- **Performance Analysis**: Reward metrics and optimal action selection

## Key Concepts
- Epsilon-Greedy strategies (ε = 0.1)
- Sample averages for action-value estimation
- Constant step-size parameter (α = 0.1) for nonstationary problems
- Random walk dynamics: q_t(a) = q_{t-1}(a) + N(0, σ²)
- Performance evaluation over multiple runs
