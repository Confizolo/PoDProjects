# Machine Learning (ML)

## Overview
This directory contains laboratory assignments and exercises for the Machine Learning course, covering fundamental ML algorithms and techniques.

## Contents

### Lab Sessions
- **intro_to_labs/**: Introduction to ML laboratory environment and tools
- **lab1/**: First laboratory assignment covering basic ML concepts
  - ASSIGNMENT_Lab1.ipynb: Main assignment notebook
- **lab2/**: Second laboratory session on ML algorithms
- **Lab3/**: Third laboratory focusing on advanced ML techniques

## Topics Covered
- Introduction to machine learning concepts
- Supervised learning algorithms
- Model training and evaluation
- Data preprocessing and feature engineering
- ML algorithm implementation and analysis

## Technologies
- **Language**: Python
- **Format**: Jupyter Notebooks (.ipynb)
- **Expected Libraries**: scikit-learn, NumPy, Pandas, Matplotlib
