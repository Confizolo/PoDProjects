# Neural Networks and Deep Learning (NNDL)

## Overview
This directory contains homework assignments for the Neural Networks and Deep Learning course, focusing on implementing and training various neural network architectures.

## Contents

### Homework Assignments
- **HW1/**: First homework - Introduction to neural networks
- **HW2/**: Second homework - Advanced architectures
- **HW3/**: Third homework - Deep learning techniques

### Environment
- **environment.yml**: Conda environment specification with dependencies
  - PyTorch framework
  - Scientific computing libraries (NumPy, SciPy, Pandas)
  - Visualization tools (Matplotlib, Bokeh)
  - Jupyter notebook support
  - Deep learning utilities

## Topics Covered
- Neural network fundamentals
- Deep learning architectures
- Training and optimization techniques
- Model evaluation and analysis
- PyTorch implementation

## Technologies
- **Language**: Python
- **Deep Learning Framework**: PyTorch
- **Key Libraries**: 
  - torch, torchvision
  - NumPy, Pandas
  - Matplotlib, Seaborn
  - Jupyter
- **Environment**: Conda (Python 3.8)

## Setup
```bash
conda env create -f environment.yml
conda activate torch
```
