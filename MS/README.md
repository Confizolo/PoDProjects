# Molecular Simulations (MS)

## Overview
This project contains molecular dynamics simulation analysis, focusing on computational chemistry and statistical mechanics applications.

## Contents

### Main Components
- **analysis.ipynb**: Primary analysis notebook
  - MDTraj-based trajectory analysis
  - Density calculations
  - Integration and visualization
  - LaTeX-quality figure generation

### Directories
- **src/**: Source code and simulation scripts
- **figures/**: Generated plots and visualizations
- **presentation/**: Project presentation materials
- **report/**: Written reports and documentation

## Analysis Features
- Molecular trajectory analysis using MDTraj
- Statistical analysis of simulation data
- Publication-quality figure generation
- Integration methods for property calculations

## Technologies
- **Language**: Python
- **Key Libraries**:
  - MDTraj: Molecular dynamics trajectory analysis
  - NumPy: Numerical computations
  - SciPy: Scientific computing and integration
  - Matplotlib: Visualization with LaTeX styling
- **Format**: Jupyter Notebook

## Output
The project generates publication-ready figures with proper LaTeX formatting for scientific reports and presentations.
